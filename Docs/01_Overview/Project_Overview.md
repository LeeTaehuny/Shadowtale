# 프로젝트 개요 — Shadowtale

## 한 줄 소개
잠 못 드는 아이에게 엄마가 읽어주는 그림 동화책 속에서, 3D 오브젝트로 벽의 그림자 그림을 재현해 페이지를 완성하고 그 그림 속 주인공이 되어 모험하는 그림자 퍼즐 게임.

## 스토리 프레임
- **프롤로그**: 아이 방. 아이가 잠이 오지 않고, 엄마가 그림 동화책을 펼친다. 책이 클로즈업되며 책 속 세계로 들어간다.
- **페이지 반복**: 한 페이지 = 하나의 3D 공간 + 벽에 붙은 동화책 페이지(그림자 그림).
- **에필로그**: 마지막 페이지를 마치면 책이 닫히고 아이가 잠든다.

## 핵심 게임 루프
1. 페이지 진입: 3D 공간에 들어선다. 벽의 동화책 페이지에는 주인공 캐릭터와 특수 물건(상자 등)이 그림자로만 그려져 있다.
2. 탐색·운반: 3인칭 캐릭터로 공간의 오브젝트를 들고 다닌다.
3. 배치: 오브젝트를 광원 앞에 놓고 위치·회전을 맞춰 벽의 목표 그림자와 같은 그림자를 만든다.
4. 변환: 그림자가 일치하면 벽의 그림자가 실제 2D 그림(채색된 일러스트)으로 바뀐다.
5. 페이지 완성: 페이지의 모든 그림자(페이지당 2~4개 예상)를 완성하면 벽 그림으로 카메라가 클로즈업된다.
6. 2D 플레이: 완성된 그림 속 주인공 캐릭터를 조작해 횡스크롤 퍼즐 또는 전투를 수행한다.
7. 페이지 넘김: 다음 페이지로 넘어가 1로 돌아간다.

## 타깃 / 플랫폼
- PC (Steam, Windows). 키보드·마우스 + 게임패드(Xbox 레이아웃 기준).
- 해상도 기준 1920×1080, 60fps. Steam Deck 대응은 나중에 검토.

## 기술 스택
- Unity: 6000.3 LTS (Unity 6.3)
- 렌더 파이프라인: URP, 카툰(툰) 렌더링 — 방식은 [[ADR-0002-toon-rendering]]에서 결정
- 주요 패키지: Input System, Cinemachine 3.x, URP, Shader Graph, Unity Test Framework
- 후보(ADR 후 도입): Unity Toon Shader, DOTween, Steamworks.NET

## 범위
- 포함: 프롤로그/에필로그, 3D 그림자 퍼즐, 그림자→2D 그림 변환 연출, 2D 횡스크롤 페이지 플레이(퍼즐·간단한 전투), 페이지 넘김, 세이브(페이지 단위)
- 제외(이번 버전 아님): 멀티플레이, 레벨 에디터 배포, 모바일·콘솔, 다국어(한국어·영어 외)

## 마일스톤
| ID | 목표 | 완료 기준 |
|---|---|---|
| M1 | 3D 그림자 퍼즐 수직 슬라이스 | 테스트 페이지 1장: 3인칭으로 오브젝트 2개를 운반·배치해 그림자 2개를 맞추면 2D 그림으로 변하고 "페이지 완성" 이벤트가 발생 |
| M2 | 2D 페이지 플레이 | 페이지 완성 → 벽 그림 클로즈업 → 횡스크롤 캐릭터로 간단한 퍼즐 1개 클리어 → 3D로 복귀/다음 페이지 |
| M3 | 동화책 프레임 | 프롤로그(아이 방 → 책 클로즈업), 페이지 넘김 연출, 에필로그(책 닫힘), 페이지 단위 세이브 |
| M4 | 콘텐츠 & 아트 | 페이지 N장, 카툰 아트 스타일 확정, 사운드 |
| M5 | 출시 준비 | Steam 연동, 옵션/키 리바인딩, 빌드 파이프라인 |

## 학습 목표
- 이 프로젝트로 익히고 싶은 유니티 기능:
  - URP 구조(URP Asset / Renderer / Renderer Feature), 실시간 그림자 설정
  - Shader Graph로 카툰 셰이딩, 그림자→그림 전환 이펙트
  - Input System, Cinemachine 3, CharacterController
  - ScriptableObject 기반 데이터 설계, asmdef, Unity Test Framework
  - 3D ↔ 2D 플레이 전환(카메라·물리·씬 구성)

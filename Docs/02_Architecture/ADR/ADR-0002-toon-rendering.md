# 카툰 렌더링 방식

## 맥락
동화책 분위기의 카툰 렌더링이 필요하다. 동시에 이 게임은 **실시간 그림자 자체가 게임플레이**라서, 카툰 셰이딩이 그림자 수신·투사를 깨면 안 된다. 렌더 파이프라인은 URP로 확정했다.

## 고려한 대안
| 대안 | 장점 | 단점 |
|---|---|---|
| A. Shader Graph 커스텀 라이팅 (메인 라이트 방향 + 그림자 감쇠를 램프 텍스처로 계단화) | 완전한 제어, Shader Graph 학습, 그림자 벽 전용 효과와 같은 도구로 통일 | 추가 라이트·그림자 샘플링을 직접 구성해야 함 (Custom Function 노드 필요) |
| B. Unity Toon Shader 패키지 (`com.unity.toonshader`) | 기능 풍부(아웃라인, 림, 그림자 색 지정), 빠른 결과 | 설정 항목이 많고 무거움, Unity 6.3 대응 여부 확인 필요(확실하지 않음), 그림자 벽 효과는 어차피 따로 만들어야 함 |
| C. 에셋 스토어 툰 셰이더 | 즉시 사용 | 의존성·라이선스, 학습 효과 낮음 |

## 결정
(초안) **A를 기본**으로 하되, T-009에서 A와 B를 같은 테스트 씬에 두고 비교한 뒤 확정한다. 판단 기준: 그림자 벽에 떨어지는 그림자의 가독성, 셰이더 수정 용이성, 성능.

## 언리얼과 비교
언리얼은 디퍼드 기반이라 툰은 보통 포스트 프로세스 머티리얼이나 엔진 수정(커스텀 셰이딩 모델)으로 푼다. URP는 포워드(또는 Forward+) 렌더러라 **머티리얼 셰이더 자체에서 라이팅을 계산**할 수 있어, 엔진 수정 없이 오브젝트별 툰 셰이딩이 가능하다.
